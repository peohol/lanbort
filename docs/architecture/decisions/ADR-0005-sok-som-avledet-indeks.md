# ADR-0005 — Søk er avledet indeks, aldri tilgangs- eller sannhetskilde

**Status:** Vedtatt
**Forankring:** PS-NFR-001, PS-NFR-002, UX-IA-004

## Beslutning

Tekst-/geosøk kan bruke egen indeks, men bare med avledede oppdagbare data. Autoritativ tilgang og faktisk ledighet verifiseres mot domenekjernen før detaljvisning eller handling.

## Begrunnelse

Dette reduserer risikoen for at stale søkedata eller indekseringsfeil lekker skjulte miljøer eller tillater ugyldige lån.
